# Low-cost fibre specklegram sensor for noncontact continuous patient monitoring

Project page for the article

> A. Rodríguez-Cuevas, E. Real Peña, L. Rodríguez-Cobo, M. Lomer and J. M. López-Higuera, "Low-cost fiber specklegram sensor for noncontact continuous patient monitoring", *Journal of Biomedical Optics* 22(3), 037001 (2017). [doi:10.1117/1.JBO.22.3.037001](https://doi.org/10.1117/1.JBO.22.3.037001) (open access)

## Contents

- `index.html`, `assets/`: the page, served with GitHub Pages. No build step and no external dependencies.
- `assets/media/`: photographs of the test bed, recorded specklegrams and the result figures of the article.
- `assets/app.js`: the live demonstrations. The traces come from a simple model of the frame-to-frame intensity change; heart rate and movement are computed from them with the three methods and the movement detector described in the article.
